# `ai-m`（当前二开项目）本地工作流平台实施检查表

**版本：** 2.0  
**使用方式：** 每张拉取请求逐项勾选，并在描述中附测试或审计证据。

# A. 架构与责任边界

- [ ] 浏览器只引用生成配置编号；
- [ ] 网页请求不执行长推理；
- [ ] 独立工作进程可单独启动和停止；
- [ ] 任务、尝试、工件、后端、资源池和修订版分开；
- [ ] 业务代码不识别工作流节点编号；
- [ ] 第三方客户端被自有接口隔离；
- [ ] 原漫剧业务语义未改变。

# B. 服务端配置和密钥

- [ ] 后端只由管理员登记；
- [ ] 密钥只保存引用；
- [ ] 普通接口不回显密钥；
- [ ] 请求和错误日志不记录认证头；
- [ ] 浏览器旧密钥迁移有安全流程；
- [ ] 后端地址执行解析地址和网段校验；
- [ ] 禁止重定向；
- [ ] 局域网后端使用传输加密和认证。

# C. 工作流供应链

- [ ] 上传进入隔离区；
- [ ] 解包有限额和路径检查；
- [ ] 结构约束拒绝未知字段；
- [ ] 语义选择器必须唯一；
- [ ] 编译计划绑定工作流摘要；
- [ ] 自定义节点固定提交摘要；
- [ ] 平台安全策略独立；
- [ ] 冒烟测试在隔离后端；
- [ ] 双人审查；
- [ ] 发布目录只读；
- [ ] 撤销机制可用。

# D. 环境验证

- [ ] 记录引擎、运行时、加速后端和节点摘要；
- [ ] 模型记录大小和摘要；
- [ ] 环境变化使验证过期；
- [ ] 节点信息缓存按环境指纹；
- [ ] 客户端任务编号经过行为探测；
- [ ] 取消能力经过行为探测。

# E. 持久任务和并发

- [ ] 原子领取；
- [ ] 资源池槽位持久化；
- [ ] 工作领取和资源槽位使用不同字段及令牌；
- [ ] 两类防旧写令牌单调递增且不重置；
- [ ] 所有关键写入检查令牌；
- [ ] 心跳和租约时长合理；
- [ ] 失去租约后工作器停止写入；
- [ ] 项目配额和公平性；
- [ ] 数据库事务短。

# F. 提交、恢复和重试

- [ ] 网络提交前持久化关联编号；
- [ ] 生产后端预分配任务编号；
- [ ] 提交禁用自动重试和重定向；
- [ ] 响应丢失进入对账；
- [ ] 证据不足进入人工处理；
- [ ] 外部历史只作证据；
- [ ] 收集失败只重试收集；
- [ ] 提交失败只重试提交；
- [ ] 错误分类决定重试；
- [ ] 已有工件阻止模型重跑。

# G. 取消

- [ ] 页面区分请求取消和确认取消；
- [ ] 优先按任务取消；
- [ ] 共享后端禁用全局中断；
- [ ] 专用后端中断前验证目标任务；
- [ ] 取消与完成竞态有事务规则；
- [ ] 已提交工件不会被取消逻辑删除。

# H. 实时连接和轮询

- [ ] 传输层没有任意路径和方法的通用代理；
- [ ] 网关限制允许的方法和路径；
- [ ] 每后端一个连接管理器；
- [ ] 连接代次；
- [ ] 事件去重；
- [ ] 进度合并写；
- [ ] 断线退避和抖动；
- [ ] 轮询按阶段；
- [ ] 实时消息不决定最终成功。

# I. 媒体输入输出

- [ ] 输入权限校验；
- [ ] 任务专用暂存；
- [ ] 执行后端不挂载完整上传目录；
- [ ] 通用任务暂存卷不直接挂载给推理实例；
- [ ] 后端摄取目录只含当前安全租户或当前资源槽任务；
- [ ] 输出流式；
- [ ] 字节、像素、时长和数量限制；
- [ ] 魔数和安全解码；
- [ ] 外部文件名不可信；
- [ ] 同文件系统原子提交或对象存储提交协议；
- [ ] 磁盘高水位；
- [ ] 清理依据数据库归属和租约。

# J. 工件与权限

- [ ] 工件不可变；
- [ ] 数据库存储系统键而非外部绝对路径；
- [ ] 下载再次校验项目权限；
- [ ] 私有原始声音单独可见性；
- [ ] 工件摘要和来源追踪；
- [ ] 重新生成保留版本历史。

# K. `Z-Image`（造相文生图模型）

- [ ] 快速和质量配置分离；
- [ ] 真实生产工作流已晋级；
- [ ] 宽高、像素和倍数策略；
- [ ] 随机种子无精度损失；
- [ ] 用户不能覆盖模型文件或任意节点输入；
- [ ] 角色图和镜头图入口回归；
- [ ] 云端图片供应商仍可用。

# L. 测试与质量

- [ ] 旧流程特征测试；
- [ ] 单元测试；
- [ ] 结构约束测试；
- [ ] 假后端集成测试；
- [ ] 提交不确定测试；
- [ ] 工作器终止测试；
- [ ] 租约竞态测试；
- [ ] 磁盘满测试；
- [ ] 大文件测试；
- [ ] 服务端请求伪造测试；
- [ ] 越权工件测试；
- [ ] 真实设备验收；
- [ ] 样例自动校验通过。

# M. 可观测性与运维

- [ ] 统一关联编号；
- [ ] 阶段耗时指标；
- [ ] 提交不确定告警；
- [ ] 租约失效告警；
- [ ] 环境漂移告警；
- [ ] 磁盘水位告警；
- [ ] 日志字段白名单；
- [ ] 运维处理不确定任务的页面；
- [ ] 备份和恢复演练。

# N. 发布与回滚

- [ ] 功能开关服务端控制；
- [ ] 小范围项目灰度；
- [ ] 回滚不删除新表和工件；
- [ ] 默认配置可回退；
- [ ] 运行中任务有排空方案；
- [ ] 工作流撤销测试；
- [ ] 浏览器旧密钥清理；
- [ ] 发布后漫剧回归通过。
