# `ai-m`（当前二开项目）本地工作流平台迁移与回滚计划

**版本：** 2.0

# 1. 迁移原则

- 先加后切，先兼容后清理；
- 新表和新工件可被旧代码忽略，但不能被旧代码破坏；
- 密钥迁移优先安全，不追求无感；
- 运行中任务在切换前排空或显式冻结；
- 修订版和工件不做破坏性回滚；
- 每阶段都有功能开关、观测和回滚演练。

# 2. 当前风险数据

- 浏览器持久化供应商地址和密钥；
- 默认模型引用旧供应商和模型编号；
- 旧业务任务状态；
- 外部绝对资源路径；
- 运行中的云端或本地任务；
- 未版本化的工作流和提示参数。

# 3. 上线顺序

## 阶段 A：只加表和兼容代码

创建执行后端、资源池、工作流修订版、生成配置修订版、任务、尝试、工件和事件表。旧流程不切换。

## 阶段 B：服务端配置与双读

管理员录入服务端后端和密钥引用。页面优先读取新生成配置；缺失时只读旧配置。

## 阶段 C：能力服务切换

旧供应商通过兼容适配器进入新能力服务。建立回归基线。

## 阶段 D：持久工作进程

新生成任务进入独立工作进程；旧任务继续原逻辑直到排空。

## 阶段 E：本地图片

仅对内部测试项目启用本地快速配置；逐步扩大范围。

## 阶段 F：停止旧密钥写入

设置页不再接受浏览器持久化密钥；保留只读迁移提示。

## 阶段 G：清理旧结构

至少经过一个稳定发布周期、备份和回滚演练后，才删除旧写路径。历史读取适配可保留更久。

# 4. 浏览器密钥迁移

## 4.1 安全优先模式

管理员在服务端重新录入密钥，验证成功后页面清除旧浏览器数据。提示轮换长期暴露过的密钥。

## 4.2 一次性迁移模式

仅在确有必要时启用：管理员再认证、一次性短期令牌、同源、禁止请求正文日志、立即保存为密钥引用、成功后清除本地值、失败不回显密钥。

## 4.3 失败处理

迁移失败保持旧云端流程但阻止创建新的浏览器密钥；显示明确错误；不把密钥写入错误报告。

# 5. 默认模型迁移

建立旧供应商和模型编号到生成配置修订版的显式映射。无法唯一映射时要求管理员选择，不按名称模糊匹配。项目级默认、用户级默认和全局默认分别迁移。

# 6. 任务迁移

## 6.1 运行中任务

发布前进入排空模式；无法排空的任务记录清单，禁止自动转换外部编号语义。

## 6.2 历史任务

历史资源继续按旧路径读取。只有在验证文件存在、摘要和权限后才可迁移为新工件。

## 6.3 新旧并存

关系表连接旧业务任务和新生成任务。页面根据来源展示，不把旧状态硬映射为新尝试阶段。

# 7. 工件和路径

相对路径保持。绝对路径需先验证位于允许目录、读取内容、计算摘要并复制到新存储；不能仅改数据库字符串。不可访问的历史资源标记缺失，不伪造成功。

# 8. 功能开关

- 服务端生成配置读取；
- 新能力服务；
- 持久工作进程；
- 本地工作流；
- 新工件存储；
- 新设置页面；
- 声音能力。

开关必须服务端控制并有审计，不能成为绕过安全策略的永久双轨。

# 9. 回滚策略

## 9.1 代码

关闭新入口，恢复旧默认指针。新表和工件保留。

## 9.2 数据库

只回滚可逆索引和读取路径，不删除已写修订版、任务和工件。结构迁移使用向前修复优先。

## 9.3 工作流

撤销新工作流或生成配置，默认指针回到上一修订版。运行中任务仍使用冻结快照。

## 9.4 后端

禁用异常后端，停止新任务，已有任务进入观察或人工处理。不要迁移正在运行的外部任务到另一后端。

# 10. 回滚演练

- 新配置发布后回到旧云端；
- 工作进程升级失败后使用旧工作进程读取新任务；
- 数据库迁移中断；
- 新工件已提交但代码回滚；
- 工作流撤销；
- 后端环境漂移；
- 浏览器密钥迁移失败。

# 11. 完成判定

- [ ] 旧浏览器密钥已清除或明确进入轮换清单；
- [ ] 默认指针全部可解释；
- [ ] 运行中旧任务已排空；
- [ ] 新工件可在回滚版本读取；
- [ ] 原漫剧回归通过；
- [ ] 回滚演练有记录；
- [ ] 旧写路径已停止；
- [ ] 破坏性清理尚未提前执行。
