# ADR-0003：工作流和自定义节点属于可执行供应链

- **状态：** 已接受
- **日期：** 2026-07-12

## 背景

工作流可选择自定义节点。节点代码可能读写文件、访问网络或执行命令。结构约束只能验证形状，不能证明代码安全。

## 决策

工作流包必须经过隔离上传、限额解包、静态策略、语义编译、环境验证、隔离冒烟、双人审查和只读发布。自定义节点按提交摘要固定，执行环境采用最小权限。

## 被否决方案

- 允许普通用户上传后直接运行；
- 只检查扩展名和结构约束；
- 让工作流作者自报安全；
- 在主应用容器内执行节点。

## 后果

工作流发布变慢，需要管理员和测试环境；但避免把任意代码执行能力交给内容上传者。

## 验证

危险节点、未知节点、环境漂移和包路径攻击被自动阻止；未发布摘要不能被生成配置引用。
