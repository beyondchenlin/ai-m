# ADR-0004：`SQLite`（嵌入式数据库）仅支持单主机持久执行

- **状态：** 已接受
- **日期：** 2026-07-12

## 背景

第一阶段希望复用现有数据库，但持久任务会增加领取、心跳、进度、事件和工件提交写入。网络文件系统和多主机共享会破坏锁语义和可靠性。

## 决策

第一阶段仅允许同一主机的网页进程和工作进程共享本地数据库文件。启用预写式日志、外键、忙等待、短事务、事件合并和备份恢复。多主机前迁移到服务型数据库。

## 迁移触发条件

多主机工作器、持续锁等待影响页面、高可用要求、需要行级跳过锁定或高频审计写入。

## 后果

单机部署简单且可控，但不能把数据库文件放在网络共享盘，也不能将其包装成多主机集群。

## 验证

并发领取、续租、取消、进度和工件提交测试通过；网络文件系统部署在启动时被拒绝或文档明确不支持。
