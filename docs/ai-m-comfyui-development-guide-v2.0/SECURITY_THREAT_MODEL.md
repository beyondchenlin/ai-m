# `ai-m`（当前二开项目）本地工作流平台安全威胁模型

**版本：** 2.0  
**范围：** 控制平面、工作进程、执行后端、工作流供应链、媒体暂存、项目工件和声音样本。

# 1. 安全目标

- 密钥不进入浏览器、普通日志和任务快照；
- 普通用户不能让服务端访问任意网络目标；
- 未审查工作流和自定义节点不能进入生产执行；
- 一个项目不能读取另一项目的输入和工件；
- 恶意媒体不能耗尽内存、磁盘和解码资源；
- 陈旧工作器不能覆盖新状态；
- 取消不能误伤无关任务；
- 声音克隆样本需要授权、私有存储和最小访问。

# 2. 信任边界

## 2.1 不可信

- 浏览器请求参数；
- 上传文件名、扩展名和媒体类型；
- 工作流压缩包；
- 预览图和说明文档；
- 外部历史、队列、实时事件和输出元数据；
- 用户输入提示词；
- 第三方自定义节点；
- 第三方客户端库的行为假设。

## 2.2 受控但可能故障

- 网页进程；
- 工作进程；
- 数据库；
- 媒体存储；
- 反向代理；
- 服务端密钥解析器。

## 2.3 隔离执行平面

- `ComfyUI`（本地工作流引擎）实例；
- 模型文件；
- 自定义节点；
- 任务专用输入和输出目录。

# 3. 主要威胁与控制

## T-01：浏览器密钥泄漏

**控制：** 服务端密钥引用、管理员权限、禁止公开环境变量、日志脱敏、一次性迁移和轮换。

## T-02：服务端请求伪造

**控制：** 后端服务端登记、协议白名单、解析地址检查、地址固定、禁止重定向、网段白名单、代理绕过测试。

## T-03：任意工作流或节点代码执行

**控制：** 隔离上传、节点类策略、自定义节点固定提交、无特权容器、网络最小化、双人审查和撤销。

## T-04：压缩包路径穿越和资源耗尽

**控制：** 文件数、展开大小、压缩比、路径、符号链接和硬链接限制；解包到隔离目录。

## T-05：预览和说明内容注入

**控制：** 预览安全解码重编码；说明纯文本或严格净化；禁止脚本和外部资源。

## T-06：外部输出路径穿越

**控制：** 不信任外部路径；系统生成存储键；真实路径约束到允许根目录；拒绝链接。

## T-07：超大媒体和解压炸弹

**控制：** 流式字节限额、像素和时长限额、解码资源限制、超时、磁盘高水位。

## T-08：任务状态篡改和陈旧写

**控制：** 数据库状态机、租约、防旧写令牌、条件更新、不可变快照和事件审计。

## T-09：取消误伤

**控制：** 优先按任务取消；共享后端禁用全局中断；专用后端验证当前任务和租约。

## T-10：日志和诊断泄漏

**控制：** 字段白名单、密钥和路径脱敏、提示词摘要、诊断权限和保留期。

## T-11：工件越权读取

**控制：** 工件编号查询后再次校验项目权限；下载不接受任意路径；私有原始声音特殊权限。

## T-12：密钥迁移端点滥用

**控制：** 管理员再认证、一次性令牌、同源、跨站请求伪造防护、请求正文不记录、使用后失效。

## T-13：第三方依赖替换或行为变化

**控制：** 锁定版本和完整性、适配层、契约测试、行为探测、依赖更新审查。

## T-14：声音克隆样本滥用

**控制：** 明示授权、用途记录、私有加密存储、最小挂载、删除流程、禁止公共链接、审计访问。

## T-15：工作流安全策略被作者放宽

**控制：** 平台安全策略独立存储和签发；工作流不能携带可执行规则或任意正则。

## T-16：域名重绑定和主机名欺骗

**控制：** 完整主机名边界、解析所有地址、连接地址固定、证书主机校验、重探测。

## T-17：资源饥饿和拒绝服务

**控制：** 项目配额、有界队列、像素和批量限制、资源池、公平调度、磁盘水位和管理员熔断。

## T-18：跨任务输入目录泄漏

**控制：** 后端摄取目录独立于通用暂存区；资源槽并发为一或按租户分实例；只复制当前任务输入；租约保护清理；跨用户强隔离使用短生命周期执行容器。

## T-19：通用接口代理被用于全局破坏操作

**控制：** 传输接口类型化；固定方法与路径白名单；生成凭据不能调用队列清空、历史删除和用户数据写入；管理操作独立授权和审计。

# 4. 安全配置基线

## 4.1 后端

- 默认禁用；
- 启用前通过行为探测和环境验证；
- 远程必须传输加密和认证；
- 禁止自动重定向；
- 允许工作流摘要白名单；
- 地址和网段白名单；
- 密钥只用引用。

## 4.2 工作流包

- 拒绝未知字段；
- 内容寻址；
- 只读发布；
- 节点和输入安全策略；
- 双人审查；
- 冒烟测试；
- 环境变化失效。

## 4.3 工件

- 流式、限额、摘要和安全解码；
- 暂存与提交分离；
- 项目权限；
- 生命周期和清理审计；
- 不信任外部文件名。

## 4.4 容器

- 非根用户；
- 只读根文件系统；
- 删除所有能力；
- 禁止新增权限；
- 无容器套接字；
- 内部推理网络；
- 任务专用挂载；
- 模型只读；
- 默认无外网。
