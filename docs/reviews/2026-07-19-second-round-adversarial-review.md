## 3. 仍未关闭的发布阻塞

### P0-01：六包真实执行失败

新代际 `5a40f8bb7c4b8a0f437aca2a73c85e532a9c72e5963acc242992ec4d494d9681` 的首包 `tts-index2` 在真实后端执行失败，未产生可导入证据。IndexTTS2 要求 `transformers==4.52.1` 或 `4.54.1`，OmniVoice 要求 `transformers>=5.3.0`，单一解释器没有版本交集。

关闭标准：批准许可证完整的替代实现或单一公开端点后的隔离执行环境；把解释器、锁文件、节点提交、本地补丁、启动参数和路由版本纳入环境锁；生成新代际并从首包完整重跑六包。

### P0-02：商业授权未闭环

当前 IndexTTS2 插件声明许可证来自 `LICENSE`，但上游和安装副本均缺少该文件。技术评估不能替代复制、修改和分发授权。

关闭标准：取得权利人可核验许可或改用许可证完整的实现；保存代码、模型和传递依赖的软件物料清单、义务、批准人和日期；完成法务书面结论。

### P1-01：操作系统访问隔离失败

推理与应用使用同一 Windows SID，目录继承宽泛访问控制。专用基础目录只能证明参数隔离，不能证明禁止读取。

关闭标准：使用独立低权限服务身份或等价容器身份；禁止目录真实读取失败、必需目录读取成功；重启后结果不漂移；随后完成六包和十八类故障。

### P1-02：真实故障注入未完成

自动化普通故障三轮和并发二十轮只属于前置证据。真实响应丢失、后端终止、工作进程六阶段终止、启停失败、就绪超时、下载中断、关闭与恢复仍未完成。

关闭标准：实现故障执行器；FI-01～FI-18 按矩阵强制轮次运行；每轮机器判定数据库、资源、工件、进程、端口和后端请求；每组后执行正常任务；无残留才通过。

### P1-03：两阶段回滚只有计划，没有真实版本

`04d1ace` 会拒绝包含未来迁移的日志。兼容过渡版本尚未实现、冻结或演练。

关闭标准：形成不含 0063～0068、但只读容忍批准未来追加迁移的独立提交；先完成其发布和回滚，再发布功能候选；隔离副本上旧读新、恢复候选、表和逐行摘要均一致。

### P1-04：当前机器不能完成双人和身份隔离实证

当前只有一个可用 Windows SID，也没有获批的独立低权限服务账户。代码不能伪造第二主体或借用工具沙箱账户。

关闭标准：导入者与两名审查者使用三个真实认证主体完成记录；服务账户由项目负责人批准并配置最小访问控制；证据保存登录令牌主体、时间和不可变包环境摘要。

### P1-05：Windows 目录断电耐久协议未实现

验证器现在会安全拒绝，但安全拒绝不等于能力完成。目标平台仍不能提供已证明的目录同步。

关闭标准：在目标卷验证进程崩溃、主机重启和模拟断电，或实现带摘要序号的双清单或写前日志；对写入、改名、刷新、重放各阶段注入故障，恢复器不得接受半提交。
